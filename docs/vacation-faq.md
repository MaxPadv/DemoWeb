# FAQ «Знак вопроса» на странице «Запланировать отпуск»

Статус: **as-built** (реализовано субагентом, проверено ассистентом).

## As-built

- Кнопка `vc-faq` («?») справа от заголовка «Запланировать отпуск», в `.vc-title-row` (flex).
- Показ по наведению (`onMouseEnter`/`onMouseLeave`) и по клику (`onClick` → открыть; не toggle —
  иначе клик при наведённой мыши закрывал подсказку).
- Подсказка `vc-faq-tip`: заголовок «FAQ Планирования отпусков:» + 4 пункта (`ul/li`),
  absolute-позиционирование относительно `.vc-title-row`, в корп. стиле (фон `--sogaz-bg`,
  тень, `var(--radius)`, 13px).
- Исправлен баг: `onClick` ставил `toggle`, конфликтуя с `onMouseEnter(true)` — подсказка
  закрывалась при клике.

## Цель

На странице «Запланировать отпуск», рядом с надписью «Запланировать отпуск» (справа от неё),
добавить значок **«?»** в стилистике страницы. При наведении или нажатии — показывать подсказку
по планированию отпусков (тоже в стиле страницы).

## Текст подсказки (FAQ)

```
FAQ Планирования отпусков:
- Посчитайте свои дни.
- Обсудите с руководителем.
- Решите, делить ли отпуск на части.
- Учтите льготы.
```

## Где и как

- `services/vacations/frontend/src/VacationsApp.tsx` — в экране планирования (`PlanVacations`)
  рядом с `<h1 className="vc-title">Запланировать отпуск</h1>` (в `.vc-head-main`, внутри блока
  заголовка): обернуть заголовок в flex-строку и добавить справа кнопку-значок.
- Классы: кнопка `vc-faq` (значок «?»), подсказка `vc-faq-tip`.
- Поведение: при `hover` (mouseenter/leave) и по клику (toggle) показывать/скрывать подсказку;
  для доступности — `aria-expanded`/`aria-label`.
- Стиль: в корпоративном стиле страницы (цвет `--sogaz-brand`/`--sogaz-*`, скругление, hover),
  подсказка — как карточка/тултип (фон `--sogaz-bg`, тень, радиус, размер текста как у
  существующих подсказок `vc-msg`/`pc-tooltip`), буллеты списком.
