# Фича: тултип на дне календаря (чья отпуск / пересечение)

Статус: **реализовано** (as-built, после ревью).

## Что сделано

- При наведении на квадрат дня в календаре показывается **тултип справа от курсора**
  (отступ ~10px; у краёв экрана переворачивается влево/вверх).
- Для каждого отпуска, покрывающего день, — строка «<start> — <end> · <Имя Фамилия>» (DD.MM.YYYY).
- При пересечении (2+ отпуска на дне) — каждый отпуск своей строкой + строка
  **«Пересечение: <start> — <end>»** (перекрытие = `max(start)..min(end)` периодов).
- Тултип компактный: 13px, тёмная подложка, белый текст, тень, radius, max-width 320px, z-index
  поверх; скрывается при уходе курсора. Позиционирование через `getBoundingClientRect` (mousemove).
- Данные дня расширены: day → массив отпусков `{employee, start, end}` (вместо только имён).

## Зачем

При наведении на квадрат дня в календаре — подсказка, что за отпуск и чей. Если пересечение —
показать оба отпуска. Удобно читать, не перегружая интерфейс.

## Решение (по уточнению пользователя)

- Наведение на ячейку дня → **тултип справа от курсора** (с отступом; у края экрана переворачивается).
- Содержимое: строки «<start> — <end> · <Сотрудник>» для **каждого** отпуска, покрывающего этот день.
  При пересечении — **каждый отпуск своей строкой** (первая строка — первый, вторая — второй).
- Если на дне несколько отпусков (пересечение) — дополнительная строка **«Пересечение: <start> — <end>»**
  (перекрытие периодов: напр., отпуск 01.06–14.06 и 03.06–10.06 → пересечение 03.06–10.06).
- Тултип компактный, читаемый, не закрывает интерфейс (небольшой шрифт, контрастная подложка,
  тень, высокий z-index, max-width).

## Срезы

- **T1 — данные**: для каждого дня — список отпусков, покрывающих день (`{employee, start, end}`),
  а не только имена. Логика пересечения (перекрытие периодов) при 2+ отпусках на дне —
  `max(start)..min(end)`.
- **T2 — UI тултипа**: рендер при наведении (mousemove), позиционирование справа от курсора,
  flip у краёв, скрытие при уходе.
- **T3 — стили**: тултип (фон/тень/шрифт), перенос строк, z-index.

## Ограничения

- Только `remotes/vacations` (VacationsApp.tsx / styles.css). Бэкенд, данные, другие remotes не трогать.
